# Stamp 本機驗收

純靜態網站，沒有套件、編譯或 build 步驟。

在專案根目錄啟動：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

- 編輯器：http://127.0.0.1:8765/
- 桌機回歸：http://127.0.0.1:8765/tests/editor.html
- 390px 手機版回歸：http://127.0.0.1:8765/tests/editor.html?mobile
- 語法檢查：`node --check script.js`
- 空白檢查：`git diff --check`

測試頁以人工產生的 RGB 圖測試原圖上傳、多區正反向框選、滑鼠／touch PointerEvent、CSS 座標映射、區內外像素、亮度與重設、撤銷、格子大小、清除／還原、重繪無累積損失、PNG 編碼解碼像素一致、印章圖層獨立、更換圖片與原有印章大小／角度。下載流程測試攔截 anchor click，驗證檔名與有效 PNG Blob。

已在 Mac Chrome 執行桌機、390px 版測試；另以實際滑鼠在縮小預覽拖曳兩區成功。合成 touch 事件不等於手機實機驗證，尚未在 iOS／Android 實機測試。

Chrome 擴充功能自動選檔因未開啟檔案網址權限失敗，未修改此設定；原生選檔工具逾時。實際下載工具也逾時，未確認 OS 下載落地，故以 PNG 像素與下載處理函式驗證代替。

## 使用與限制

- 亮度 0–200%，100% 為原圖；格子大小 4–100 原圖像素，只套用目前選取區域；未選取時設定新區域預設。
- 開啟「框選馬賽克」後在預覽拖曳，可多區；Esc 或觸控取消事件會取消當次框選。
- 共用底圖編輯撤銷紀錄保留最近 50 步；既有專案無 undo，因此新增此紀錄。印章控制維持原有流程。
- 更換圖片會清除框選、亮度與底圖撤銷紀錄；格子大小和印章設定沿用。
- 處理始終從原始 Image 重建，先亮度、再馬賽克、最後印章。超大圖片的亮度運算在主執行緒，可能較慢。
- 遠端印章仍依賴既有 ImageKit 連線與 CORS；沒有新增浮水印／文字功能，現有 repo 只有印章圖層。
- 本次正式更新沿用 main 分支既有 GitHub Pages 部署；JS／CSS 版本參數為 `20261021-2`。

## 選取框 UX 更新

放開後保留靜態黑白虛線框；可點選既有區域（重疊時取最後新增）或清單切換。格子大小只改目前區域；未選取時設定新區域的預設大小。取消選取／Esc 僅隱藏選框，不刪效果。框線為 DOM overlay，不寫入 PNG。未使用動畫。

額外測試包含保留選框、區域切換、獨立格子大小、取消／Esc 不損效果、縮放對齊、可見選框下的 PNG 無框線。手機仍為 390px 版面與合成觸控事件，非實機驗證。
